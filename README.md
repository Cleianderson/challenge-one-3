Este repositório contém o código do desafio Telecom X BR do Programa ONE.

## 📝 Descrição

Neste desafio, a Telecom X está sofrendo com uma grande onda de rescisão de contratos de seus clientes. Diante desta situação, a empresa pretende realizar uma análise dos contratos a fim de descobrir uma explicação para este aumento na evasão.
